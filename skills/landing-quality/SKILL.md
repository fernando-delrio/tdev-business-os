# Skill: landing-quality

## Purpose
Evaluate a landing page as a commercial product and an engineered experience, not merely as a visual composition.

## Dimensions
1. Positioning and message clarity
2. Narrative and information architecture
3. Trust and proof
4. Conversion path and CTA friction
5. UX and responsive behavior
6. Visual differentiation / anti-template quality
7. Accessibility
8. Performance / Core Web Vitals risk
9. SEO fundamentals
10. Technical maintainability

## T·DEV creative quality heuristics
Flag common AI/developer-portfolio clichés when they are decorative rather than meaningful: gratuitous neon, particles, code rain, holograms, generic SaaS cards, excessive glow, random motion and effects without narrative purpose.

Animation must have an interaction contract. For scroll-driven sequences, define progress mapping, reversibility, pause behavior, mobile fallback, reduced motion and layout-shift constraints before implementation.

## Output
For every issue:
- finding
- evidence
- business/user impact
- recommendation
- priority
- confidence

Then produce:
- top 5 changes by leverage
- explicit `keep` list so successful design is not accidentally redesigned
- implementation acceptance criteria
- pre/post measurement plan

## Rule
A more impressive effect is not automatically a better landing page. Protect clarity, performance, accessibility and conversion.
