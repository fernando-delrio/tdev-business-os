# T·DEV implementation

This directory contains business-specific overlays for T·DEV. It is intentionally separate from the reusable Business OS core.

Current implementation surface:

- configuration schema: [`../../config/tdev.example.yaml`](../../config/tdev.example.yaml);
- cinematic landing extension: [`quality-gates/cinematic-intro.md`](quality-gates/cinematic-intro.md).

Future T·DEV positioning, market intelligence, commercial constraints, and verified proof may be referenced from here or the T·DEV config. Do not populate them with assumptions. Private pricing, prospect/client data, credentials, and private conversations must remain outside the repository.

The actual T·DEV website and product code live in a separate repository. This implementation layer may define briefs and gates; it does not contain or deploy that code.
